# SlideQuest – Hand Gesture Controlled Puzzle Game

SlideQuest is an interactive sliding puzzle game that allows
users to solve puzzles using real-time hand gestures captured
through a webcam.

## Features
- Interactive sliding puzzle gameplay
- Real-time webcam hand tracking
- Finger movement-based tile selection
- Pinch-and-drag gesture interaction
- Camera preview alongside the puzzle
- Modular JavaScript architecture

## Technologies Used
- HTML
- CSS
- JavaScript
- MediaPipe Tasks Vision

## Project Structure
- game.js – Puzzle game logic
- cameraManager.js – Camera management
- handTracker.js – Hand landmark detection
- gestureController.js – Gesture recognition and controls

## How to Run
1. Clone this repository.
2. Install the required dependencies.
3. Run the application using the configured development server.
4. Allow webcam access when prompted.
